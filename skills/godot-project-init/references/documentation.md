# 官方文档快照

默认快照位于 `assets/docs/godot/4.7/`。它来自官网链接的 HTML 离线包，经版本检查后转换；正文不摘要。
manifest.json 固定归档 SHA256、转换器版本、抓取时间、每页源与 Markdown 哈希。4.7 文档分支不保证严格对应 4.7.2 每个补丁细节。

## 显式更新

用 local.json 中的 Python（安装了 beautifulsoup4、markdownify）运行：

```powershell
& <Python> scripts/sync_docs.py --archive <工作目录中的ZIP> --output <新的快照目录> --version 4.7 --url <官网提供的离线归档URL> --sha256 <已确认的归档哈希>
```

脚本拒绝版本不匹配及在现有快照上混写另一归档/转换器。先在新目录转换并检查，再显式更新技能资产及项目。
下载支持有限重试、缓存及服务器支持时的 Range 续传。中断转换可针对相同归档/输出目录再次执行，按已保存哈希跳过完整页面。
可使用本地已有 ZIP，无需联网。不要每次初始化重新下载随时间变化的 stable 包。

## 覆盖边界

保留官方教程、类参考、参数、警告、代码块和必要表格。生成的搜索/总索引工具页以本地 CATALOG.md/search_index.json 取代。
HTML 原始锚点用少量 `<a id="…"></a>` 保留，避免 Markdown 自动锚点与 Godot API 命名不一致。
源站本身缺少的锚点记录在清单中，并降级为目标正文页链接；不发明 API 锚点。
图片、视频、音频保留原站地址而不复制二进制，因此离线镜像以文字与代码为主。正文许可与署名必须随快照保留。

## 核验

运行 `scripts/verify_docs.py --path <镜像目录>`，确认文件哈希、页数、代码围栏和本地链接。
抽检场景组织、Resource/Node API、GDScript 风格、命令行；检查表格、示例缩进和警告。
未完成时保留失败清单，不把部分镜像标成完整。换版本先验证归档版本元信息。
