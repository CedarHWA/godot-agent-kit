# Android in-app purchases

Godot provides the first-party [GodotGooglePlayBilling](https://github.com/godotengine/godot-google-play-billing) Android plugin for integrating the [Google Play Billing library](https://developer.android.com/google/play/billing), enabling applications distributed through Google Play to offer one-time purchases and subscriptions.

For installation, setup instructions, and the API reference, see the [GodotGooglePlayBilling documentation](https://godot-sdk-integrations.github.io/godot-google-play-billing/).
