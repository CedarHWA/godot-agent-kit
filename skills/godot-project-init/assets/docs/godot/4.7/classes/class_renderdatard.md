# RenderDataRD

**Inherits:** [RenderData](class_renderdata.md#class-renderdata) **<** [Object](class_object.md#class-object)

Render data implementation for the RenderingDevice based renderers.

<a id="description"></a>

## Description

This object manages all render data for the [RenderingDevice](class_renderingdevice.md#class-renderingdevice)-based renderers. See also [RenderData](class_renderdata.md#class-renderdata), [RenderSceneData](class_renderscenedata.md#class-renderscenedata), and [RenderSceneDataRD](class_renderscenedatard.md#class-renderscenedatard).

**Note:** This is an internal rendering server object. Do not instantiate this class from a script.
