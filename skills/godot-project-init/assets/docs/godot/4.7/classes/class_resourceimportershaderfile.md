# ResourceImporterShaderFile

**Inherits:** [ResourceImporter](class_resourceimporter.md#class-resourceimporter) **<** [RefCounted](class_refcounted.md#class-refcounted) **<** [Object](class_object.md#class-object)

Imports native GLSL shaders (not Godot shaders) as an [RDShaderFile](class_rdshaderfile.md#class-rdshaderfile).

<a id="description"></a>

## Description

This imports native GLSL shaders as [RDShaderFile](class_rdshaderfile.md#class-rdshaderfile) resources, for use with low-level [RenderingDevice](class_renderingdevice.md#class-renderingdevice) operations. This importer does *not* handle `.gdshader` files.
