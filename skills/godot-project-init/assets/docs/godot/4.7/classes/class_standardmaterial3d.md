# StandardMaterial3D

**Inherits:** [BaseMaterial3D](class_basematerial3d.md#class-basematerial3d) **<** [Material](class_material.md#class-material) **<** [Resource](class_resource.md#class-resource) **<** [RefCounted](class_refcounted.md#class-refcounted) **<** [Object](class_object.md#class-object)

A PBR (Physically Based Rendering) material to be used on 3D objects.

<a id="description"></a>

## Description

**StandardMaterial3D**'s properties are inherited from [BaseMaterial3D](class_basematerial3d.md#class-basematerial3d). **StandardMaterial3D** uses separate textures for ambient occlusion, roughness and metallic maps. To use a single ORM map for all 3 textures, use an [ORMMaterial3D](class_ormmaterial3d.md#class-ormmaterial3d) instead.
