# ColorRect

**Inherits:** [Control](class_control.md#class-control) **<** [CanvasItem](class_canvasitem.md#class-canvasitem) **<** [Node](class_node.md#class-node) **<** [Object](class_object.md#class-object)

A control that displays a solid color rectangle.

<a id="description"></a>

## Description

Displays a rectangle filled with a solid [color](class_colorrect.md#class-colorrect-property-color). If you need to display the border alone, consider using a [Panel](class_panel.md#class-panel) instead.
