# TextureCubemapRD

**Inherits:** [TextureLayeredRD](class_texturelayeredrd.md#class-texturelayeredrd) **<** [TextureLayered](class_texturelayered.md#class-texturelayered) **<** [Texture](class_texture.md#class-texture) **<** [Resource](class_resource.md#class-resource) **<** [RefCounted](class_refcounted.md#class-refcounted) **<** [Object](class_object.md#class-object)

Texture for Cubemap that is bound to a texture created on the [RenderingDevice](class_renderingdevice.md#class-renderingdevice).

<a id="description"></a>

## Description

This texture class allows you to use a cubemap texture created directly on the [RenderingDevice](class_renderingdevice.md#class-renderingdevice) as a texture for materials, meshes, etc.

**Note:** **TextureCubemapRD** is intended for low-level usage with [RenderingDevice](class_renderingdevice.md#class-renderingdevice). For most use cases, use [Cubemap](class_cubemap.md#class-cubemap) instead.
