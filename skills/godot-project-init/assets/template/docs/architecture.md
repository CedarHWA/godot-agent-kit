# 当前架构

`scenes/main/main.tscn` 是入口和组装位置，包含 World 与 UI；当前没有游戏系统或 Autoload。
以后按需求添加功能场景，由其拥有内部节点和状态。全局服务仅在需要跨场景生命周期时引入。

重要变更记录：日期、需求、选择、理由、公共接口、替代方案的取舍、验证方式。

实现完整功能前补充简短树/表：功能 → 场景/内置节点 → 配置资源 → 运行状态所有者 → 命令/事件 → 编辑入口及消费者。独立面板、棋盘、角色能力按编辑/替换/生命周期划分，不只是列出脚本文件。自绘或自定义布局等选择记录实际需要及预览/调参方式；小修不重写整份设计。

目录按类型＋功能子目录组织，场景与脚本相对功能路径对应；配置和媒体按实际需求加入 resources/ 与 assets/。这不改变场景自包含、父级注入和资源可编辑的要求。
